Política de Privacidade

1. Coleta de Dados

Coletamos apenas os dados necessários para o funcionamento do sistema jurídico.

2. Uso dos Dados

Os dados são utilizados exclusivamente para:

  • Autenticação e autorização de usuários
  • Processamento de documentos jurídicos
  • Análise e geração de relatórios

3. Proteção dos Dados

Implementamos medidas técnicas e organizacionais para proteger seus dados:

  • Criptografia de dados em trânsito e repouso
  • Controle de acesso baseado em funções
  • Logs de auditoria

4. Seus Direitos (LGPD)

Você tem direito a:

  • Acessar seus dados pessoais
  • Corrigir dados incorretos
  • Solicitar exclusão de dados
  • Revogar consentimento
  • Portabilidade de dados

5. Contato

Para questões sobre privacidade, entre em contato através do sistema.
