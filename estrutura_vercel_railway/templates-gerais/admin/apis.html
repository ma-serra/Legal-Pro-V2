Configurações Avançadas
Se habilitado, o sistema tentará usar o provedor de fallback em caso de falha.
Se habilitado, o sistema armazenará resultados de consultas repetidas para economizar chamadas de API.
Sistema de Fallback Inteligente

O sistema utiliza uma ordem específica de fallback para garantir alta disponibilidade:

  1. Anthropic (Claude) - Primeira opção de fallback para processamento de texto jurídico de alta qualidade
  2. Google (Gemini) - Segunda opção de fallback para processamento quando Anthropic não estiver disponível
  3. Deepseek - Terceira opção de fallback para casos em que os provedores anteriores não estejam disponíveis
  4. Grok - Quarta opção de fallback para casos em que os provedores anteriores não estejam disponíveis

Esta ordem foi otimizada para garantir a melhor qualidade de processamento de textos jurídicos em caso de indisponibilidade do provedor principal.
