Configuração da Integração com Taskade

Token de API do Taskade

Forneça seu token de API do Taskade para configurar a integração. Você pode obter esse token no painel de desenvolvedor do Taskade.

Exemplo: tskdp_XXXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX
Voltar
Como obter um token de API do Taskade
  1. Faça login na sua conta do Taskade.
  2. Acesse as configurações da sua conta no canto superior direito.
  3. Navegue até a seção "Developer" ou "API".
  4. Gere um novo token de API e copie-o.
  5. Cole o token no campo acima e clique em "Salvar Configurações".

Como funciona o OAuth 2.0

Ao clicar em "Autorizar com Taskade", você será redirecionado para o site do Taskade para autorizar nossa aplicação a acessar seus dados. Após a autorização, você será redirecionado de volta para nossa aplicação.

Configuração OAuth Incompleta

A configuração OAuth 2.0 para o Taskade não está completa. Para ativar este método de autenticação, é necessário configurar as variáveis de ambiente:

  • TASKADE_CLIENT_ID: ID do cliente OAuth
  • TASKADE_CLIENT_SECRET: Segredo do cliente OAuth

Essas credenciais podem ser obtidas registrando um aplicativo OAuth no painel de configurações do Taskade.

Vantagens do OAuth 2.0
  • Segurança aprimorada: Você não precisa compartilhar suas credenciais do Taskade com nossa aplicação.
  • Acesso limitado: Você controla exatamente quais permissões nossa aplicação tem.
  • Revogação fácil: Você pode revogar o acesso a qualquer momento diretamente no Taskade.
  • Experiência de usuário melhor: Não é necessário copiar e colar tokens de API.
