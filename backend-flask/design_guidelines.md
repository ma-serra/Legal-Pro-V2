# Legal Pro Mastercard Predictive System - Design Guidelines

## Design Approach
**System-Based Approach**: Using Bootstrap 5 as the foundation with Mastercard brand integration for this enterprise legal analytics platform. The design prioritizes utility and data comprehension while incorporating strategic brand elements.

## Core Design Elements

### A. Color Palette
**Primary Colors:**
- Mastercard Red: 345 92% 42% (#eb001b)
- Mastercard Orange: 23 100% 50% (#ff5f00)

**Dark Mode Foundation:**
- Background: 220 13% 9%
- Surface: 220 13% 11%
- Card backgrounds: 220 13% 13%
- Text primary: 0 0% 98%
- Text secondary: 220 5% 65%

**Supporting Colors:**
- Success: 142 69% 45%
- Warning: 38 92% 50%
- Danger: 0 84% 60%
- Info: 207 90% 61%

### B. Typography
- **Primary**: Inter (Google Fonts) - clean, data-friendly
- **Headers**: Inter Bold/Semi-bold for KPI titles, dashboard headers
- **Body**: Inter Regular for content, data labels
- **Monospace**: JetBrains Mono for case numbers, legal references

### C. Layout System
**Spacing Units**: Bootstrap's rem-based system (0.25, 0.5, 1, 1.5, 3, 4, 5)
- Common spacing: p-3, m-4, gap-3 for consistent rhythm
- Dashboard grids: 12-column responsive system
- Card spacing: p-4 for content areas

### D. Component Library

**Navigation**
- Dark sidebar with Mastercard gradient accent
- Collapsible navigation with legal analytics icons
- Breadcrumb system for case navigation

**Dashboard Cards**
- Dark cards (220 13% 13%) with subtle borders
- KPI cards with large numerical displays
- Mastercard color accents for positive metrics
- Rounded corners (0.75rem) for modern feel

**Data Visualization**
- Charts using Mastercard color scheme
- Interactive tooltips with dark backgrounds
- Gradient overlays: Red to orange for performance metrics
- Progress bars with brand colors

**Forms & Inputs**
- Dark input fields with subtle borders
- Mastercard orange focus states
- Floating labels for legal case data entry
- Multi-select dropdowns for case categories

**Case Simulator**
- Modal-based interface with dark backdrop
- Step-by-step wizard using Bootstrap's nav-pills
- Results displayed in highlighted cards
- Confidence indicators using brand colors

### E. Interactive Elements

**Buttons**
- Primary: Mastercard red with white text
- Secondary: Outline style with orange borders
- On images: Semi-transparent background with blur effect

**Data Tables**
- Zebra striping in dark theme
- Sortable headers with orange indicators
- Pagination with brand color accents
- Row hover states for case selection

**Charts & Visualizations**
- Donut charts for case outcome distributions
- Line graphs for trend analysis over time
- Heat maps for judicial decision patterns
- Bar charts comparing success rates

## Special Features

**Dashboard Layout**
- Three-column responsive grid for KPIs
- Central area for main visualizations
- Sidebar filters with legal category selectors
- Quick action buttons for new case analysis

**Gradients & Visual Treatments**
- Subtle gradients from Mastercard red to orange on hero elements
- Card shadows with warm undertones
- Hover states with gentle orange glows
- Status indicators using brand color intensity

**Responsive Considerations**
- Collapsible sidebar for mobile
- Stacked KPI cards on smaller screens
- Horizontal scroll for data tables
- Simplified visualizations for touch interfaces

## Images
- **Dashboard Screenshots**: Placeholder analytics screenshots showing legal data visualizations
- **Legal Icons**: Scales of justice, gavel, document icons integrated with Mastercard styling
- **Case Study Graphics**: Abstract representations of legal decision trees
- **No Large Hero Image**: Focus remains on functional dashboard interface

This design maintains Legal Pro's analytical focus while strategically incorporating Mastercard's brand identity through color, spacing, and interactive elements.
